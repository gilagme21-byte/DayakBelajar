DAYAKBELAJAR - VERSI LATAR BELAKANG HTML/CSS

Isi folder:
- index.html
- style.css
- script.js
- kosakata.json

Tidak ada gambar eksternal yang dibutuhkan. Latar belakang beranda dan elemen dekoratif dibuat langsung menggunakan HTML dan CSS.

Cara menjalankan:
1. Buka folder ini di Visual Studio Code.
2. Jalankan index.html menggunakan Live Server.
3. Pastikan kosakata.json berada satu folder dengan index.html.

Game mengambil 8 pasangan kosakata secara acak dari kosakata.json.
Setiap pasangan benar bernilai 10 poin.
